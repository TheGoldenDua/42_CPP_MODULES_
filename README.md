## 🧠 Overview

The **C++ Modules** series from 42 introduces students to **object-oriented programming (OOP), class design, and advanced C++ concepts**.  

Projects in these modules typically cover:
- **Class constructors, destructors, and copy semantics**  
- **Encapsulation, inheritance, and polymorphism**  
- **Operator overloading**  
- **Exception handling**  
- **Templates and STL basics**  

The goal is to master writing **robust, modular, and maintainable C++ code** following modern OOP practices.

---

## 🧩 Key Objectives

- Design and implement classes with proper constructors, destructors, and copy methods  
- Apply **encapsulation** using private/protected members  
- Implement **operator overloading** and custom behaviors  
- Handle exceptions and edge cases gracefully  
- Write reusable and modular C++ code
